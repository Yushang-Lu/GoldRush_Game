## 根因

1. **曼哈顿贪心不理解迷宫拓扑。** 遇到挡墙只在两个直达方向间切换，会进入
   局部最小值或在死路反复折返。
2. **固定中心分工错过了更大的外围供给。** 一个守中心、一个 5x5 追最大值的
   设计在开放图可依赖速度抢币，在新图却无法穿过窄道覆盖外围生成点。
3. **单目标与非联合搜索浪费六步。** 实际有效动作不足一半，两个单位也会长期
   收益失衡。
4. **没有 NPC 风险估值。** 新日志我方累计损失 1270；当前输入中已出现 3+
   NPC 的格子本可直接规避。
5. **后手时的计划位置会失真。** 对手先占据一步后，旧代码仍按“该步成功”的
   位置规划剩余动作；窄道和死路放大了这个问题。

故意让策略变慢并不能获得新的当轮信息：双方的 `GameInput` 在任何角色行动前
已经固定。慢策略获胜来自额外计算带来的路线质量，而不是“后手观察”。因此最终
方案保留深搜，但继续尽量缩短它的实际延迟。

## 候选对比

`fast-player2` 当时看到的输入，不能生成候选的新轨迹；有状态最终版还会把
