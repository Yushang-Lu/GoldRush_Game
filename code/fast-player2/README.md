# Fast Player 2

这是一个独立提交单元，默认产物为 `code/fast-player2/player.so`，不会覆盖
`code/player.cpp`、`code/player.so` 或第一版 `code/fast-player/`。

## 日志结论

本次分析的 9 局日志中，第一版 `Yushang6` 总战绩为 3 胜 6 负：

| 对手 | 战绩 | 日志中的 P90 | 可见策略特征 |
| --- | ---: | ---: | --- |
| `player10` | 0-3 | 0.42-0.46 us | 两单位大多贴近中心，约 498-500/500 轮先行动 |
| `player147` | 3-0 | 1.95-2.14 us | 明显更慢，每局购买 25 次 9x9 视野 |
| `player226` | 0-3 | 0.94-1.01 us | 一个主力承担约 93.4% 的可见拾币，另一个单位活动很少 |

第一版自身 P90 为 1.04-1.13 us。它只有面对更慢的 `player147` 时稳定
先行动；对另外两个对手通常在 NPC 之后行动。9 局共记录到 972 金币的
持币下降（炸弹和踩踏合计），全部出现在这些更快的对手局中。第一版的
主力还会为 5x5 内的目标离开核心区，若干局中到 `(8,8)` 的平均曼哈顿
距离达到 3-4 格；`player10` 则更集中在中心。

由此，第二版同时针对两个问题：把热路径降到对手之下，争取在 NPC 和
对手前执行；将无目标移动约束在中心 3x3，而不是继续向外漂移。

## 策略

- 无 BFS、历史地图、堆分配、随机数和视野购买，`vp` 恒为 0。
- u0 使用 3x3 扫描，向 `(8,8)` 迁移并守点；无金币且已到中心时不分配
  步数，有金币时分配 2 或 3 步并利用离开/重入重复拾取。
- u1 是主力。用 AVX2 的 5 次掩码向量读取完成完整 5x5（25 格）最大金币
  扫描，再走一条有固定上界的直达路径；两条同长路径优先经过金币更多的
  中间格。
- 抵达金币后，剩余步数用于离开再进入，以继续拾取余币；没有目标时在
  中心 3x3 环上每轮移动 2-3 步。
- 主力先执行。路径不进入当前迷雾、已知墙、已知炸弹、可见敌人、另一己方
  单位的当前/最终占位格。
- 为保持热路径足够短，不统计 NPC 聚集，也不记忆已经离开视野的炸弹。这是
  有意的速度/风险权衡。

Release 构建使用 `-march=x86-64-v3`（包含 AVX2），没有使用
`-march=native`。赛事文档所列运行 CPU 支持 AVX2；若部署到更老的 x86-64
CPU，需要改用相应的 ISA 构建。

## 构建与验证

从仓库根目录执行：

```bash
make -C code/fast-player2
make -C code/fast-player2 verify
make -C code/fast-player2 test
make -C code/fast-player2 sanitize
make -C code/fast-player2 bench
make -C code/fast-player2 compare
make -C code/fast-player2 replay
```

- `test`：50,000 个确定性模糊输入和定向边界测试。
- `sanitize`：20,000 个输入的 ASan/UBSan 构建；该构建不用于计时或提交。
- `bench`：默认 3 轮、每轮 100,000 次 Release 调用。
- `compare`：用完全相同的 Release 参数临时重编译第一版，交错测量两者，
  并要求第二版 P90/第一版 P90 不超过 `0.40`。
- `replay`：在 9 局原始输入上比较两版的即时可见收益和慢手折价代理。

样本数和门槛可覆盖：

```bash
make -C code/fast-player2 compare \
  COMPARE_SAMPLES=300000 COMPARE_RUNS=5 MAX_RATIO=0.40
```

清理本目录构建产物：

```bash
make -C code/fast-player2 clean
```

## 当前离线结果与限制

在本轮开发机的一次 500,000 样本 x 5 轮交错测量中，第一版 P90 为
0.627 us，第二版为 0.189 us，比值 30.1%，即本地 P90 约降低 69.9%。
第二版五轮独立 P90 为 0.188-0.193 us，P99 为 0.245-0.277 us；一次
409.452 us 的最大值是未反映到 P99/P90 的主机调度离群点。
在 9 局日志的反事实回放中：

- 即时可见拾币代理：第一版 17,667，第二版 16,856（95.4%）；
- 慢手折价净值代理：第一版 15,558，第二版 14,868（95.6%）；
- 第二版模型路径的已知炸弹损失、记忆炸弹风险、迷雾移动和阻塞均为 0。

回放只是把两版输出应用到第一版当时看到的同一输入，不能重建第二版移动后
的视野、对手/NPC 响应或最终胜率。这里的延迟也只是本地实测，不是赛事成绩；
新版本仍需真实引擎对局验证轨迹变化和已有 3 个以上 NPC 格子的风险。
